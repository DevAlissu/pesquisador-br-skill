## Pluralidade epistemológica

⚠️ Os autores listados em `autores-classicos-br.md` são **referência canônica de metodologia científica**, não restrição de bibliografia. A skill encoraja **pluralidade**: ao revisar literatura, sugere autores decoloniais (Boaventura, Mignolo), feministas (hooks, Crenshaw, Lélia González), indígenas (Davi Kopenawa) e outros, conforme o tema.

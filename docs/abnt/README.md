## Como a skill usa

A skill `pesquisador-br` carrega esses arquivos automaticamente quando o pipeline atinge etapas de **citação**, **referência** ou **formatação**. O usuário não precisa abrir manualmente — basta invocar `/pesquisador-br` e seguir o fluxo.

## Fonte oficial

Para o texto integral das normas (com todos os exemplos oficiais), adquira via [ABNT Catálogo](https://www.abntcatalogo.com.br). O conteúdo aqui é **interpretação aplicada** com base nas normas, não cópia integral.

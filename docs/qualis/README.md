## Como a skill usa

Quando o usuário pergunta "qual o Qualis dessa revista?" ou "que revistas A da minha área?", a skill consulta esses arquivos para:
- Identificar a **área CAPES** correta
- Explicar o **estrato Qualis**
- Indicar o passo a passo de consulta no Sucupira

⚠️ **Importante**: Qualis é por quadriênio. Os arquivos aqui refletem **2017-2020** (vigente em abr/2026). A skill sempre orienta o usuário a verificar o quadriênio mais recente na Sucupira.

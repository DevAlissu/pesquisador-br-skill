# Capítulo 3 — Metodologia (TCC)

> Padrão **Gil (2017)** para classificação de pesquisa, com 4 eixos obrigatórios + procedimentos detalhados.

## Estrutura recomendada

```
3 METODOLOGIA

3.1 Tipo e abordagem da pesquisa
3.2 Sujeitos / corpus / objeto
3.3 Procedimentos de coleta de dados
3.4 Procedimentos de análise dos dados
3.5 Aspectos éticos (se aplicável)
```

---

## 3.1 Tipo e abordagem da pesquisa

Classifique nos **4 eixos** de Gil (2017) e Marconi & Lakatos (2017).

```
A presente pesquisa caracteriza-se, quanto à **natureza**, como
[básica/aplicada]. Quanto à **abordagem**, classifica-se como
[qualitativa/quantitativa/mista]. Em relação aos **objetivos**,
trata-se de pesquisa [exploratória/descritiva/explicativa].
Os **procedimentos** adotados configuram [estudo de caso/
levantamento/etnografia/pesquisa bibliográfica/pesquisa-ação/
experimental/ex-post-facto] (GIL, 2017; MARCONI; LAKATOS, 2017).

A escolha justifica-se por [argumento de coerência com a
pergunta de pesquisa].
```

⚠️ Cite **sempre** as referências metodológicas (Gil, Marconi & Lakatos, ou outros equivalentes).

---

## 3.2 Sujeitos / corpus / objeto

Descreva **quem** ou **o quê** foi pesquisado.

### Pra pesquisa empírica com sujeitos

```
Participaram da pesquisa [N] sujeitos, selecionados por
[critério de seleção: amostragem por conveniência, intencional,
bola de neve, aleatória]. Os critérios de **inclusão** foram:
(i) [critério]; (ii) [critério]. Como critérios de **exclusão**:
(i) [critério]; (ii) [critério].

A caracterização dos sujeitos é apresentada na Tabela 1.
```

| Variável | n | % |
|---|---|---|
| Idade (média ± dp) | XX,X ± Y,Y | — |
| Gênero — Feminino | XX | XX% |
| Gênero — Masculino | XX | XX% |
| Escolaridade — Médio | XX | XX% |
| Escolaridade — Superior | XX | XX% |

### Pra pesquisa documental

```
O corpus de análise é composto por [N] documentos, selecionados
no período de [data] a [data], conforme os seguintes critérios:
(i) [critério]; (ii) [critério]. As fontes consultadas foram:
[base 1], [base 2], [base 3].
```

### Pra pesquisa bibliográfica / revisão

```
A revisão foi conduzida nas bases [SciELO, Periódicos CAPES,
BDTD, etc], no período [data]. Os descritores utilizados foram:
[lista]. A combinação por operadores booleanos resultou em [N]
referências, das quais [N] foram incluídas após triagem.
```

⚠️ Pra revisão sistemática, use **PRISMA-PT** completo (ver `revisao-sistematica-br` skill).

## 3.3 Procedimentos de coleta

Detalhe **como, quando, onde, com que instrumento**.

```
A coleta de dados ocorreu entre [data] e [data], no/na
[local físico ou virtual]. Utilizou-se [instrumento — questionário
estruturado / semi-estruturado / roteiro de entrevista / observação
sistemática / análise documental] (apresentado no Apêndice A).

[Detalhamento do instrumento]
O instrumento contemplou [N] questões/itens, organizados em
[N] blocos: (i) [bloco 1]; (ii) [bloco 2]; [...].

[Procedimento de aplicação]
Os participantes foram convidados via [meio]. As entrevistas/
aplicações ocorreram [presencial/online via plataforma X],
com duração média de [N] minutos. As entrevistas foram gravadas
em áudio e posteriormente transcritas.
```

### Instrumentos comuns

| Instrumento | Características | Quando usar |
|---|---|---|
| Questionário estruturado | Perguntas fechadas, escala Likert | Survey quanti |
| Questionário semi-estruturado | Mistura aberta/fechada | Mista |
| Roteiro de entrevista | Tópicos guia, abertura | Quali |
| Observação sistemática | Protocolo + ficha | Etnografia, sala de aula |
| Diário de campo | Anotações livres | Imersão prolongada |
| Análise documental | Documentos primários | Pesquisa histórica, política |
| Grupo focal | Discussão em grupo | Quali, percepções coletivas |

## 3.4 Procedimentos de análise

Como os dados foram tratados? **Com que técnica**?

### Análise quantitativa

```
Os dados foram tabulados em [Excel/SPSS/R/STATA] e analisados
por meio de **estatística descritiva** (frequência, média,
desvio-padrão) e **estatística inferencial** (teste t / qui-
quadrado / ANOVA / regressão / correlação).

Adotou-se nível de significância de p < 0,05. Os softwares
utilizados foram [nome + versão].
```

### Análise qualitativa

```
A análise dos dados qualitativos foi realizada conforme proposta
de Bardin (2011), em três fases: (i) **pré-análise** (leitura
flutuante, organização do material), (ii) **exploração do
material** (codificação, categorização) e (iii) **tratamento
dos resultados** (inferência e interpretação).

A unidade de registro foi o **[tema/palavra/frase]**, e a
unidade de contexto, o **[parágrafo/seção/transcrição completa]**.

A categorização seguiu procedimento [a priori / a posteriori
emergente / misto], resultando em [N] categorias e [N]
subcategorias (apresentadas no Quadro 1).
```

### Análise mista

```
Adotou-se desenho misto **[convergente paralelo / sequencial
explicativo / sequencial exploratório]** (CRESWELL; CLARK, 2018).
A integração dos dados ocorreu na fase de [interpretação /
análise / coleta], permitindo triangulação entre [...].
```

## 3.5 Aspectos éticos

⚠️ **Obrigatório** quando envolve **humanos**.

```
A pesquisa foi submetida ao Comitê de Ética em Pesquisa (CEP)
da [instituição], sendo aprovada sob o **parecer nº [número],
CAAE nº [número]**, em [data].

Todos os participantes assinaram o **Termo de Consentimento
Livre e Esclarecido (TCLE)**, sendo informados sobre os
objetivos, procedimentos, riscos, benefícios e a possibilidade
de desistência sem prejuízo. Os dados foram **anonimizados**,
identificando os sujeitos por códigos (P1, P2, ..., Pn).
```

⚠️ Pesquisa **sem CEP** com humanos não é publicável em revistas A. Mesmo TCC com pesquisa de campo precisa.

## Checklist da metodologia

- [ ] **4 eixos** classificados (natureza, abordagem, objetivos, procedimentos)
- [ ] Citações a Gil (2017) e/ou Marconi & Lakatos (2017)
- [ ] Sujeitos/corpus caracterizados (com critérios I/E)
- [ ] Instrumento detalhado (com referência ao apêndice)
- [ ] Período + local + meio de coleta
- [ ] Técnica de análise nomeada com autor (ex: Bardin, 2011)
- [ ] Software / ferramenta declarado
- [ ] Aspectos éticos (CEP/TCLE) se aplicável
- [ ] **Tempo verbal**: pretérito perfeito + voz passiva sintética
- [ ] Sem 1ª pessoa ("eu coletei" → "coletaram-se")
- [ ] Sem travessões `—`/`–`
- [ ] Apêndice com instrumento de coleta

---

## Erros comuns

❌ Não classificar nos 4 eixos (só dizer "qualitativa")
❌ Sem referências metodológicas (Gil ou equivalente)
❌ Misturar nomenclaturas (estudo de caso E etnografia E pesquisa-ação?)
❌ Sem critérios de inclusão/exclusão
❌ Não detalhar instrumento (deixar no apêndice E descrever brevemente)
❌ Análise vaga ("foi feita análise dos dados")
❌ Sem CEP em pesquisa com humanos
❌ Tempo verbal misturado (presente + pretérito)
❌ Frase em 1ª pessoa ("entrevistei 15 docentes")

---

## Tamanho típico

- TCC: **3-6 páginas**
- Mas em IC: pode ser maior (4-8)

⚠️ Curta, objetiva e replicável. **Outro pesquisador deve conseguir reproduzir** seguindo seu método.

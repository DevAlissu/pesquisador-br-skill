# Capítulo 4 — Resultados e Discussão (TCC)

> Capítulo crítico do TCC. Organize os achados de modo claro e articule com a literatura.

## Duas abordagens possíveis

### Modelo A — Resultados E Discussão integrados (recomendado pra TCC)
- Cada subseção apresenta achado + interpretação + diálogo com literatura
- Mais fluido, evita repetição
- Padrão em ciências sociais aplicadas, educação, saúde coletiva

### Modelo B — Resultados separados da Discussão
- 4 RESULTADOS (objetivos, sem interpretação)
- 5 DISCUSSÃO (interpreta + dialoga)
- Padrão em ciências exatas, saúde quantitativa

⚠️ Verifique norma do seu PPG/curso. **Modelo A é mais comum em TCC.**

---

## Estrutura recomendada (Modelo A)

```
4 RESULTADOS E DISCUSSÃO

4.1 Caracterização dos sujeitos / corpus
    [Tabela 1: perfil dos participantes]
    [Análise descritiva breve]

4.2 [Eixo de análise 1 — alinhado com objetivo específico 1]
    [Achado 4.2.1]
    [Achado 4.2.2]
    [Discussão articulando com literatura]

4.3 [Eixo de análise 2 — alinhado com objetivo específico 2]
    [Achados]
    [Discussão]

4.4 [Eixo de análise 3 — alinhado com objetivo específico 3]
    [Achados]
    [Discussão]

4.5 Síntese dos achados
    [Resposta consolidada à pergunta de pesquisa]
```

⚠️ Cada eixo (4.2, 4.3, 4.4) deve corresponder a um **objetivo específico** declarado na introdução.

---

## Como redigir cada subseção

### Estrutura do parágrafo de achado

```
[1. APRESENTAÇÃO DO ACHADO — pretérito]
Constatou-se que [achado]. Conforme demonstrado na Tabela 2,
[X% / N=]. A Figura 3 ilustra [...].

[2. DETALHAMENTO]
Especificamente, [recorte do achado]. Tal padrão se observa
em [...].

[3. INTERPRETAÇÃO]
Tal resultado sugere [interpretação]. Diante disso, considera-se
que [...].

[4. DIÁLOGO COM LITERATURA — convergência]
Os achados convergem com aqueles de Silva (2023), que também
identificou [...]. Em consonância com Souza (2022), observa-se
[...].

[5. DIÁLOGO COM LITERATURA — divergência ou ampliação]
Por outro lado, divergem dos resultados de Outro (2021), o que
pode ser atribuído a [diferença de contexto/método/amostra].
Nesse sentido, o presente trabalho amplia a literatura ao
[contribuição].
```

## Apresentação de tabelas (NBR 14724)

```
Tabela 2 — Perfil sociodemográfico dos participantes (n=15)

| Variável            | n    | %    |
|---------------------|------|------|
| Gênero — Feminino   | 9    | 60,0 |
| Gênero — Masculino  | 6    | 40,0 |
| Idade — 25-34 anos  | 5    | 33,3 |
| Idade — 35-44 anos  | 7    | 46,7 |
| Idade — 45+ anos    | 3    | 20,0 |

Fonte: dados da pesquisa (2026).
```

⚠️ **Regras**:
- Título **acima** da tabela (não da figura)
- Numeração contínua (Tabela 1, 2, 3...)
- Fonte **abaixo**, em fonte 10
- Sem bordas verticais; só horizontais
- Alinhamento: número à direita, texto à esquerda
- Decimais com **vírgula** (PT-BR), não ponto

---

## Apresentação de figuras (NBR 14724)

```
Figura 3 — Distribuição das categorias temáticas

[imagem ou diagrama]

Fonte: elaborado pelo autor (2026).
```

⚠️ **Regras**:
- Título **acima**, fonte **abaixo**
- "Figura" inclui gráficos, diagramas, fotos, mapas
- Resolução mínima: 300 dpi
- Se for figura de outro autor: "Fonte: Silva (2023, p. 42)."
- Se for adaptação: "Fonte: adaptado de Silva (2023, p. 42)."

---

## Apresentação de quadros (NBR 14724)

⚠️ **Diferença Tabela vs Quadro**:
- **Tabela**: dados quantitativos (números, frequências)
- **Quadro**: dados qualitativos / textuais

```
Quadro 1 — Categorias e subcategorias da análise de conteúdo

| Categoria              | Subcategoria        | Frequência |
|------------------------|---------------------|------------|
| Desafios docentes      | Falta de formação   | 23         |
|                        | Sobrecarga          | 17         |
|                        | Falta de recursos   | 14         |
| Estratégias            | Adaptação           | 19         |
|                        | Colaboração         | 12         |

Fonte: dados da pesquisa (2026).
```

## Para resultados qualitativos

### Apresentação de falas

Formato:
```
[Texto do parágrafo introduzindo o tema da subseção]

Os participantes destacaram [aspecto], conforme exemplificado:

> Eu acho que a maior dificuldade é a falta de tempo. A gente
> recebe muita coisa pra fazer e não dá conta. (P3, professora,
> 38 anos)

A fala de P3 evidencia [interpretação].
```

⚠️ **Regras**:
- Citação direta longa: recuo de 4cm, fonte 10, sem aspas
- Identifique o sujeito por **código** (P1, P2, P3...) — anonimização
- Inclua dado contextual breve (gênero, idade, profissão) **se útil**
- Comente a fala **antes ou depois**

## Análise quantitativa

### Apresentação de teste estatístico

```
Verificou-se diferença estatisticamente significativa entre
os grupos (t = 3,42; p = 0,001). O grupo experimental apresentou
média (M = 8,5; DP = 1,2) superior ao grupo controle
(M = 6,3; DP = 1,8), com tamanho de efeito grande (d = 0,9).
```

### Convenções

| Símbolo | Significado |
|---|---|
| n | tamanho da amostra |
| M | média |
| DP | desvio-padrão |
| Md | mediana |
| t | teste t |
| p | nível de significância |
| d | tamanho de efeito de Cohen |
| r | correlação |
| F | ANOVA |
| χ² | qui-quadrado |

⚠️ **PT-BR**: use **vírgula** decimal: "p = 0,05" (não "p = 0.05").

## Checklist do capítulo

- [ ] Subseções alinhadas com **objetivos específicos**
- [ ] Cada achado tem: apresentação + interpretação + diálogo com literatura
- [ ] Tabelas/figuras numeradas em sequência
- [ ] Tabela: título acima, fonte abaixo
- [ ] Figura: título acima, fonte abaixo
- [ ] Decimais com vírgula
- [ ] Sujeitos anonimizados (P1, P2...) em fala qualitativa
- [ ] Citação direta longa: recuo 4cm, fonte 10
- [ ] **Tempo verbal**: pretérito (achados) + presente (interpretação)
- [ ] Sem 1ª pessoa
- [ ] Sem travessões `—`/`–`
- [ ] Síntese final que prepara conclusões
- [ ] Tabelas/figuras citadas no texto antes de aparecerem

---

## Erros comuns

❌ Resultados sem articulação com objetivos
❌ Listar achados sem interpretar ("foi observado X. foi observado Y. foi observado Z")
❌ Discussão só de convergência (sem divergência ou ampliação)
❌ Tabela com título abaixo (quebra NBR 14724)
❌ Fonte ausente em tabela ou figura
❌ Citação direta longa entre aspas (deve ser recuada e sem aspas)
❌ Sujeitos identificados pelo nome (quebra ética)
❌ Decimais com ponto (errado em PT-BR)
❌ Tabelas/figuras sem chamada no texto
❌ Tabelas com mais de 1 página sem indicar "(continua)" / "(conclusão)"

# NBR 6023:2018 — Referências

> Norma da ABNT que define como formatar referências bibliográficas em trabalhos acadêmicos brasileiros.
> Última revisão: 2018. Está em vigor.

---

## Estrutura geral da referência

```
SOBRENOME, Prenome. Título: subtítulo. Edição. Local: Editora, ano.
```

### Elementos essenciais
- **Autor**: SOBRENOME em maiúsculas, vírgula, prenome em minúsculas (capitalize)
- **Título**: em **negrito** (preferido) ou *itálico* (se a revista usa)
- **Subtítulo**: depois de ":", sem destaque
- **Local**: cidade da publicação (não estado, não país)
- **Editora**: sem "Ed.", "Editora", "Companhia"
- **Ano**: 4 dígitos sem ponto (`2020`, não `2.020`)

### Espaçamento
- Item: **espaço simples**
- Entre itens: **espaço duplo** ou linha em branco
- Margem: alinhamento à esquerda (sem justificar)

## Por tipo de obra (com exemplos)

### 📕 Livro (autor único)

```
GIL, Antonio Carlos. **Como elaborar projetos de pesquisa**. 6. ed. São Paulo: Atlas, 2017.
```

### 📕 Livro (até 3 autores)

```
MARCONI, Marina de Andrade; LAKATOS, Eva Maria. **Fundamentos de metodologia científica**. 8. ed. São Paulo: Atlas, 2017.

CRESWELL, John W.; PLANO CLARK, Vicki L.; GARRETT, Amanda L. **Métodos de pesquisa de métodos mistos**. 2. ed. Porto Alegre: Penso, 2013.
```

### 📕 Livro (4+ autores)

```
GUIMARÃES, P. *et al.* **Inteligência artificial aplicada**. São Paulo: Bookman, 2022.
```

> **Observação**: pode-se manter todos os nomes se houver justificativa (ex: trabalho coletivo de pequeno grupo).

### 📕 Livro (organizador / coordenador)

```
MINAYO, Maria Cecília de Souza (org.). **Pesquisa social**: teoria, método e criatividade. 33. ed. Petrópolis, RJ: Vozes, 2013.
```

> Use: (org.), (orgs.), (coord.), (coords.), (ed.), (eds.).

## Convenções específicas

### Sobrenome composto / com partícula
- "Dom", "von", "van", "de la" → mantém-se com o nome quando essencial (ex: VAN GOGH, Vincent)
- "Júnior", "Filho", "Neto" → mantém com sobrenome (ex: SOUZA JÚNIOR, P.; SILVA NETO, A.)
- Sobrenomes hifenados → sob o último elemento (LÉVI-STRAUSS, Claude → STRAUSS, Claude Lévi-)

### Mesmo autor, mesmo ano
Diferenciar com letras minúsculas:
```
GIL, A. C. **Métodos de pesquisa social**. 6. ed. São Paulo: Atlas, 2008a.
GIL, A. C. **Como elaborar projetos**. 4. ed. São Paulo: Atlas, 2008b.
```

### Mesmo autor, várias obras
Pode usar travessão (6 traços) substituindo o nome:
```
GIL, A. C. **Métodos de pesquisa social**. 6. ed. São Paulo: Atlas, 2008.
______. **Como elaborar projetos**. 4. ed. São Paulo: Atlas, 2008.
```

> Mas o uso explícito (repetir nome) também é aceito e até preferido por algumas instituições.

### Sem autor (obra anônima)
Inicia pelo título com primeira palavra significativa em maiúsculas:
```
**TÍTULO** da obra: subtítulo. Local: Editora, ano.
```

### Tradução
```
SOBRENOME, P. **Título traduzido**: subtítulo. Tradução de Nome do Tradutor. Local: Editora, ano.
```

## Pontuação rápida

| Elemento | Pontuação |
|---|---|
| SOBRENOME, Prenome | vírgula entre |
| **Título**: subtítulo | dois-pontos entre, espaço |
| 6. ed. | número, ponto, "ed.", ponto |
| Local: Editora | dois-pontos |
| Editora, ano | vírgula |
| Final | ponto |
| `[...]` supressão | colchetes |
| Disponível em: URL | ponto após "em:", URL crua |
| Acesso em: dd mmm. ano | mês abreviado 3 letras + ponto (exceto maio) |

### Mês abreviado (NBR 6023)
- jan., fev., mar., abr., **maio**, jun., jul., ago., set., out., nov., dez.

## Erros frequentes a evitar

❌ `(GIL 2017)` → certo: `(GIL, 2017)` — vírgula obrigatória
❌ `Editora Atlas` → certo: `Atlas` — só nome
❌ `1ª ed.` → certo: `1. ed.` — número arábico, ponto
❌ `São Paulo, SP` → certo: `São Paulo` — sem estado
❌ `2.020` → certo: `2020` — sem ponto
❌ `acesso em 20/04/2026` → certo: `Acesso em: 21 abr. 2026.`
❌ `et al` → certo: `*et al.*` — itálico + ponto
❌ Título do artigo em negrito → certo: nome da revista é que vai em negrito
❌ Aspas no título do livro → certo: usar negrito ou itálico
❌ DOI sem URL → certo: incluir `https://doi.org/...`

---

## Como escolher: negrito ou itálico?

**Negrito** é o padrão recomendado pela ABNT. **Itálico** é aceito quando a revista exige (algumas revistas internacionais usam itálico).

**Mantenha consistência**: se escolheu negrito, use negrito em **todas** as referências.

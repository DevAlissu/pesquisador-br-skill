# NBR 15287:2011 — Projetos de Pesquisa

> Estrutura específica para projetos de pesquisa (CNPq, CAPES, FAPs estaduais).

## Aplicação

Projetos submetidos a:
- Editais de fomento (CNPq Universal, FAPESP, FAPs estaduais)
- Programas de pós-graduação (proposta de pesquisa)
- Projetos institucionais

## Estrutura

### Pré-textuais
- Capa (com identificação completa)
- Folha de rosto
- Sumário (se o projeto for longo)
- Lista de ilustrações, abreviaturas (opcional)

### Textuais (obrigatórios)

| Elemento | Conteúdo |
|---|---|
| **Tema** | Apresentação ampla do assunto |
| **Problema** | Pergunta de pesquisa específica |
| **Hipóteses** | Suposições testáveis (se aplicável) |
| **Objetivos** | Geral + específicos |
| **Justificativa** | Relevância acadêmica + prática + institucional |
| **Referencial teórico** | Conceitos-chave fundamentados |
| **Metodologia** | Tipo, sujeitos, coleta, análise, ética |
| **Cronograma** | Atividades por período |
| **Orçamento** | Detalhamento (se aplicável) |
| **Resultados esperados** | Produtos previstos |

### Pós-textuais
- Referências (NBR 6023)
- Apêndices (instrumentos, modelos)
- Anexos (cartas, parecer)

## Formatação

Mesma da NBR 14724:
- Papel A4
- Margens 3-2-3-2 cm
- Times/Arial 12 pt
- Espaçamento 1,5

## Diferenças vs trabalho acadêmico

| Aspecto | Trabalho Acadêmico (NBR 14724) | Projeto (NBR 15287) |
|---|---|---|
| Pretende ter resultados | Sim, já tem | Não — vai ter |
| Tempo verbal | Pretérito (já feito) | Futuro do presente (será feito) |
| Inclusão de cronograma | Não | Sim, obrigatório |
| Inclusão de orçamento | Não | Frequente |
| Resultados esperados | Não | Sim, obrigatório |
| Discussão | Sim | Não |
| Páginas típicas | 30-300+ | 10-50 |

## Erros frequentes

❌ Confundir projeto com artigo (escreve no pretérito)
❌ Sem pergunta de pesquisa explícita
❌ Cronograma irrealista (mestrado em 6 meses)
❌ Orçamento sem detalhamento ou fora do teto do edital
❌ Sem mostrar lacuna na literatura
❌ Sem aspectos éticos (se envolve humanos)
❌ Sem resultados esperados / produtos
❌ Sem mencionar infraestrutura disponível

# Impessoalidade no Português Acadêmico

> Texto acadêmico brasileiro **prioriza impessoalidade** — o foco é o objeto, não o pesquisador. Construções de 1ª pessoa só em casos específicos.

## Por que impessoalidade

✅ **Foca no fato**, não no autor
✅ **Distancia** o pesquisador (necessário pra rigor)
✅ **Tradição** de mais de século na escrita acadêmica BR
✅ **Padrão exigido** pela maioria dos PPGs e revistas

⚠️ Note: alguns PPGs em **antropologia, educação crítica, psicologia social** aceitam 1ª pessoa quando justificado (etnografia, autoetnografia). Mas mesmo nesses casos, **impessoalidade prevalece**.

---

## Como atingir impessoalidade

### 1. Voz passiva sintética (com `se`)

**Construção mais comum** no acadêmico BR.

| ❌ Pessoal | ✅ Impessoal |
|---|---|
| Eu observei que... | Observou-se que... |
| Eu coletei os dados | Coletaram-se os dados |
| Nós analisamos | Analisaram-se |
| Eu defendo a tese | Defende-se a tese |
| Eu apresento os resultados | Apresentam-se os resultados |
| Verifiquei | Verificou-se |

⚠️ Atenção à **concordância**: o sujeito da passiva sintética é o que vem depois.
- "Coletaram-se os dados" (dados = sujeito plural → coletaram)
- "Coletou-se a amostra" (amostra = sujeito singular → coletou)

### 2. Sujeito impessoal

| ❌ Pessoal | ✅ Impessoal |
|---|---|
| Eu acho importante | É importante |
| Acreditamos que | Acredita-se que |
| Sabemos que | Sabe-se que / É sabido que |
| Concluímos | Concluiu-se / Conclui-se |

### 3. Substantivação

Substituir verbo por substantivo:

| ❌ Pessoal | ✅ Impessoal |
|---|---|
| Quando analisamos os dados | Na análise dos dados |
| Depois que coletamos | Após a coleta |
| Quando verificamos | Mediante verificação |
| Como mostramos | Conforme demonstração |

### 4. Voz passiva analítica (com "ser/estar + particípio")

| ❌ Pessoal | ✅ Impessoal |
|---|---|
| Eu fiz a entrevista | A entrevista foi realizada |
| Nós aplicamos o questionário | O questionário foi aplicado |
| Coletamos os dados | Os dados foram coletados |

⚠️ Não exagere. **Voz passiva sintética é mais elegante** que a analítica.

### 5. "O presente trabalho", "esta pesquisa", "o autor"

| ❌ Pessoal | ✅ Impessoal |
|---|---|
| Eu apresento aqui | O presente trabalho apresenta |
| Eu argumento | A presente pesquisa argumenta |
| Defendo neste trabalho | Defende-se neste trabalho que |
| Em meu artigo | No presente artigo |

⚠️ Cuidado pra **não repetir** "o presente trabalho" excessivamente. Alterne com "esta pesquisa", "este estudo", "o estudo em tela".

## Exceções legítimas pra usar 1ª pessoa

### Onde **algumas** áreas aceitam:
- **Autoetnografia** (Antropologia, Psicologia social)
- **Pesquisa-ação militante** (Educação popular)
- **Histórias de vida** (Sociologia, Pedagogia)
- **Estudos pós-coloniais e decoloniais**
- **Carta ao editor / réplica**
- **Comunicações breves** em eventos específicos

⚠️ **Regra geral**: se o orientador / coordenador do PPG / corpo editorial não disse explicitamente que aceita, **use impessoalidade**.

### Onde **nunca** se usa 1ª pessoa:
- Resumo / abstract
- Introdução de TCC, dissertação, tese
- Resultados / discussão
- Conclusões
- Carta de submissão (use "os autores")

---

## "Nós" pode ser usado?

**Plural majestático** ou **plural de modéstia**:

```
Nós observamos que... (em vez de "Eu observei")
```

Algumas áreas aceitam (Engenharias, Computação ocasionalmente). Mas:

⚠️ **Default em PT-BR acadêmico = impessoalidade**. Use "Nós" só se:
- A área aceita (verifique normas da revista)
- É **pesquisa em equipe** (autoria múltipla)
- Você tem orientação do PPG nesse sentido

## Erros frequentes

### 1. Misturar pessoa e impessoal

❌ "Observou-se que muitos resultados foram surpreendentes. Eu fiquei impressionado com..."
✅ "Observou-se que muitos resultados foram surpreendentes, o que sugere..."

### 2. "Eu acho", "eu acredito"

❌ "Eu acho que isso é importante"
✅ "Considera-se relevante" / "Tal aspecto mostra-se relevante"

### 3. Voz passiva sintética sem concordância

❌ "Coletou-se os dados" (errado: dados = plural → coletaram-se)
✅ "Coletaram-se os dados"
✅ "Coletou-se a amostra" (singular)

### 4. Excesso de gerúndio

❌ "Estaremos verificando os resultados"
✅ "Verificar-se-ão os resultados" / "Os resultados serão verificados"

### 5. "A gente"

❌ "A gente observou" (linguagem coloquial)
✅ "Observou-se" / "A pesquisa observou"

### 6. Tempo verbal pessoal

❌ "Vou apresentar os resultados"
✅ "Os resultados serão apresentados" / "Apresentam-se os resultados"

## Tempo verbal por seção

Ver `tempo-verbal.md` para detalhes. Em resumo:

| Seção | Tempo predominante |
|---|---|
| Resumo / Abstract | Pretérito perfeito (passiva) |
| Introdução | Presente / Pretérito perfeito |
| Referencial Teórico | Presente |
| Metodologia | Pretérito perfeito (passiva) |
| Resultados | Pretérito perfeito (passiva) |
| Discussão | Presente |
| Conclusões | Pretérito perfeito + presente |
| Projeto de pesquisa | Futuro do presente |

## Modelos prontos

### Resumo
```
A presente pesquisa investigou [tema] no contexto de [recorte],
adotando [tipo de pesquisa] como abordagem metodológica.
Foram coletados [dados] mediante [instrumento], com posterior
análise por meio de [método]. Os resultados indicaram que [achado].
Conclui-se que [contribuição original].
```

### Introdução
```
O presente estudo aborda [tema], que tem suscitado interesse
crescente em [área] na última década (Autor, ano; Outro, ano).
Observa-se, na literatura, que [diagnóstico]. No entanto, persiste
a lacuna de [problema].

Diante desse cenário, levanta-se a seguinte pergunta de pesquisa:
[pergunta]. Para investigá-la, definiu-se como objetivo geral [...]
e como objetivos específicos: (i) [...]; (ii) [...]; (iii) [...].
```

### Metodologia
```
Adotou-se abordagem [qualitativa/quantitativa/mista] (Gil, 2017),
com objetivos [exploratórios/descritivos/explicativos] e
procedimentos de [estudo de caso/levantamento/experimento]
(Marconi & Lakatos, 2017).

Foram entrevistados [N] sujeitos, selecionados por [critério].
A coleta ocorreu entre [data] e [data], mediante [instrumento].
Os dados foram tratados por meio de [técnica] (Autor, ano).

A pesquisa foi aprovada pelo Comitê de Ética em Pesquisa da
[instituição], CAAE nº [número], em [data].
```

### Resultados
```
Observou-se que [achado 1] (Tabela 1), com [detalhe quantitativo].
Constatou-se ainda que [achado 2], conforme demonstrado na
Figura 3. Os dados sugerem [padrão].
```

### Discussão
```
Os achados desta pesquisa convergem com aqueles de Autor (ano),
ao identificarem [...]. Por outro lado, divergem dos resultados
de Outro (ano), que indicava [...]. Tal divergência pode ser
atribuída a [fator].
```

### Conclusões
```
A presente pesquisa investigou [tema], identificando [contribuição
original]. Verificou-se que [achado central], o que sinaliza
[implicação].

Como limitações, destacam-se [limitação]. Para pesquisas futuras,
sugere-se [agenda].
```

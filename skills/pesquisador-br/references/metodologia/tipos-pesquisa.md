# Tipos de Pesquisa Científica

> Classificação canônica usada na pesquisa brasileira, baseada principalmente em **Gil (2017)** e **Marconi & Lakatos (2017)**.

## Eixos de classificação

A pesquisa pode ser classificada em **4 eixos** simultâneos. Toda pesquisa pertence a uma categoria em cada eixo.

```
┌─────────────────────┬─────────────────────────┐
│ Eixo                │ Categorias              │
├─────────────────────┼─────────────────────────┤
│ Natureza            │ Básica / Aplicada       │
│ Abordagem           │ Quali / Quanti / Mista  │
│ Objetivos           │ Exploratória /          │
│                     │ Descritiva /            │
│                     │ Explicativa             │
│ Procedimentos       │ Bibliográfica /         │
│                     │ Documental /            │
│                     │ Experimental /          │
│                     │ Levantamento /          │
│                     │ Estudo de caso /        │
│                     │ Etnografia /            │
│                     │ Pesquisa-ação /         │
│                     │ Ex-post-facto           │
└─────────────────────┴─────────────────────────┘
```

---

## 1. Quanto à Natureza

### Pesquisa Básica (pura)
- Avança o **conhecimento teórico** sem aplicação prática imediata
- Ex: Estudar comportamento de uma proteína em laboratório

### Pesquisa Aplicada
- Gera **conhecimento pra solução de problemas práticos**
- Ex: Desenvolver vacina pra dengue, sistema de monitoramento

⚠️ Maioria de TCC, mestrado e doutorado em áreas aplicadas (Engenharias, Saúde, Educação, Computação) é **aplicada**.

---

## 2. Quanto à Abordagem

### Quantitativa
- Mensura, quantifica
- Estatística, números
- Hipóteses testáveis (deve ser refutável)
- Generalizável (com amostra adequada)

**Exemplos**: survey com 500 respondentes, medição de pressão arterial em ensaio clínico, métricas de software, regressão linear

### Qualitativa
- Compreende, interpreta
- Entrevistas, observação, análise documental
- Indutiva, contextualizada
- Profundidade > generalização

**Exemplos**: entrevista narrativa, etnografia, análise de discurso, estudo de caso aprofundado

### Mista (mixed methods)
- Combina quanti + quali
- Padrões: convergente, sequencial explanatória, sequencial exploratória
- Triangulação

**Exemplos**: questionário + entrevista, dados quanti pra contexto + quali pra aprofundar

⚠️ Uma escolha **não é melhor** que outra — depende da pergunta de pesquisa.

---

## 3. Quanto aos Objetivos

### Exploratória
- Familiariza-se com tema **pouco estudado**
- Levanta hipóteses, não testa
- Geralmente **qualitativa**

**Exemplos**: 1ª pesquisa sobre fenômeno emergente, mapear como professores BR usam IA generativa em 2026

### Descritiva
- Descreve **características** de população, fenômeno
- Estabelece relações entre variáveis sem inferir causa
- **Quanti, quali ou mista**

**Exemplos**: perfil dos egressos de uma graduação, prevalência de transtornos mentais entre estudantes universitários

### Explicativa
- Identifica **causas**
- **Variável independente → variável dependente**
- Geralmente **quantitativa**, controlada

**Exemplos**: ensaio clínico, experimento com grupo controle, regressão multivariada

⚠️ Pesquisa pode ter **mais de um** objetivo. Ex: descrever + explicar.

---

## 4. Quanto aos Procedimentos

### Bibliográfica
- **Apenas livros e artigos**
- Sem coleta empírica
- Ex: revisão sistemática, ensaio teórico

### Documental
- Documentos primários (leis, ofícios, atas, relatórios, jornais, diários)
- Diferente de bibliográfica (literatura vs documento)
- Ex: análise de processos judiciais, leis educacionais

### Experimental
- Manipulação de **variáveis**, **controle**, **grupo controle**
- Padrão-ouro pra causa
- Ex: ensaio clínico randomizado, A/B test

### Levantamento (survey)
- Questionário com amostra
- Quanti, generalizável
- Ex: pesquisa de opinião, ENEM, censo escolar

### Estudo de caso
- Análise **profunda** de **caso específico**
- Pode ser único ou múltiplos casos
- Geralmente quali, mas pode ser misto
- Ex: caso de uma escola, uma empresa, um paciente

### Pesquisa-ação
- Pesquisador **intervém** no contexto
- Cíclica: planejar → agir → observar → refletir
- Comum em educação, saúde comunitária, gestão

### Pesquisa Participante
- Pesquisador se insere na comunidade
- Não necessariamente intervém (diferença de pesquisa-ação)
- Ex: etnografia engajada

### Etnografia
- Imersão **prolongada** num grupo cultural
- Observação participante, descrição densa
- Antropologia, educação, saúde

### Ex-post-facto
- Investiga **depois** que evento ocorreu
- Sem controle sobre as variáveis
- Ex: efeitos de pandemia COVID em educação

### Pesquisa de Campo
- Coleta no contexto natural (em campo)
- Pode ser quali ou quanti

### Pesquisa de Laboratório
- Coleta em ambiente controlado
- Comum em saúde, engenharias

### Estudo Longitudinal vs Transversal
- **Longitudinal**: observa o mesmo grupo ao longo do tempo
- **Transversal**: observa diferentes grupos no mesmo momento

## Combinação típica

Toda pesquisa tem **uma classificação em cada eixo**.

### Exemplo: TCC em Educação
```
Natureza:      Aplicada
Abordagem:     Qualitativa
Objetivos:     Descritiva-explicativa
Procedimentos: Estudo de caso (uma escola pública de Manaus)
```

### Exemplo: Mestrado em Saúde Coletiva
```
Natureza:      Aplicada
Abordagem:     Mista (quanti-quali)
Objetivos:     Descritiva
Procedimentos: Levantamento (survey) + entrevista
```

### Exemplo: Doutorado em Computação
```
Natureza:      Básica (com componente aplicado)
Abordagem:     Quantitativa
Objetivos:     Explicativa
Procedimentos: Experimental (benchmarking)
```

## Como redigir a metodologia

### Estrutura padrão (NBR 14724)

```
3 METODOLOGIA

3.1 Tipo e abordagem da pesquisa
[Classificar nos 4 eixos com referências: Gil 2017, Marconi & Lakatos 2017]

3.2 Sujeitos / corpus
[Quem? Quantos? Critérios de inclusão/exclusão]

3.3 Procedimentos de coleta
[Que instrumento? Quando? Como? Onde?]

3.4 Procedimentos de análise
[Como os dados foram tratados? Software? Técnica?]

3.5 Aspectos éticos
[CEP/CONEP, TCLE, anonimização — quando envolve humanos]
```

### Tempo verbal
- **Pretérito** quando trabalho já foi feito (TCC, dissertação, tese, artigo)
- **Futuro** em projeto de pesquisa (NBR 15287)

### Voz passiva sintética
- "Foram entrevistados 15 docentes"
- "Realizou-se análise de conteúdo (Bardin, 2011)"
- "Adotou-se abordagem qualitativa"

---

## Erros frequentes

❌ **Não classificar nos 4 eixos** (só dizer "qualitativa")
❌ **Sem referência ao classificar** (sempre cite Gil ou Marconi & Lakatos)
❌ **Misturar nomenclaturas** (estudo de caso E etnografia E pesquisa-ação no mesmo trabalho?)
❌ **Confundir abordagem com objetivos** (qualitativa ≠ exploratória)
❌ **Metodologia genérica** sem detalhes (quantos? como? quando?)
❌ **Não detalhar instrumentos** (questionário, entrevista — incluir roteiro no apêndice)
❌ **Sem aspectos éticos** quando envolve humanos

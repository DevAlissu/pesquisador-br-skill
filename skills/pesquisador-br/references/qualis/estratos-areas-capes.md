# Qualis CAPES — Sistema de Classificação de Periódicos

Sistema oficial brasileiro de classificação de periódicos científicos.

---

## Estratos do Qualis Único (vigente: quadriênio 2017-2020)

| Estrato | Significado | Percentil aproximado |
|---|---|---|
| **A1** | Excelência internacional | top 12,5% (top 1/8) |
| **A2** | Excelência | 12,5% - 25% |
| **A3** | Muito boa | 25% - 37,5% |
| **A4** | Boa | 37,5% - 50% |
| **B1** | Acima da média | 50% - 62,5% |
| **B2** | Média | 62,5% - 75% |
| **B3** | Abaixo da média | 75% - 87,5% |
| **B4** | Baixa | 87,5% - 100% |
| **C** | Sem mérito acadêmico | (não recomendado) |

### Como o Qualis é calculado

Combinação de:
- **Citation metrics** (CiteScore, JCR Impact Factor, SJR)
- **Indexação** (SciELO, Scopus, Web of Science, PubMed)
- **Qualidade editorial** (peer review, periodicidade, escopo)
- **Indicadores qualitativos** específicos por área

A nota é calculada por **percentil** dentro de cada uma das 49 áreas — uma revista pode ser A1 em uma área e B2 em outra.

## Como consultar o Qualis atual

### Passo a passo

1. Acesse: https://sucupira.capes.gov.br/sucupira/public/consultas/coleta/veiculoPublicacaoQualis/listaConsultaGeralPeriodicos.jsf

2. **Evento de Classificação**: selecione **"Classificações de Periódicos Quadriênio 2017-2020"** (vigente)

3. **Área de Avaliação**: selecione a área CAPES da sua pesquisa (lista das 49 acima)

4. Filtre por:
   - **ISSN** (mais preciso)
   - **Título do Periódico** (ou parte dele)

5. Clique **"Consultar"**

6. O resultado mostra:
   - Nome do periódico
   - ISSN
   - **Estrato** (A1, A2, ..., B4, C)

### Atalho rápido

URL com filtros (substitua área):
```
https://sucupira.capes.gov.br/sucupira/public/consultas/coleta/veiculoPublicacaoQualis/listaConsultaGeralPeriodicos.jsf?eventoIni=001&areaCodigo=[CODIGO_AREA]
```

## Estratégia para escolher revista

### Pra publicar artigo

1. **Identifique a área CAPES** do seu trabalho
2. **Liste 5-10 revistas** dessa área (ou áreas afins)
3. **Consulte o Qualis** de cada uma
4. **Filtre**:
   - A1-B1: melhor pra pontuação no Lattes
   - B2-B3: aceitável, mais rápido
   - B4-C: evite (Lattes não pontua tanto, e C indica baixa qualidade)
5. **Verifique escopo** da revista (foco temático)
6. **Verifique tempo de avaliação** (se é urgente)
7. **Verifique se é open access ou paga** (custos de submissão/publicação)

### Em qual estrato mirar

| Trabalho | Mira |
|---|---|
| TCC graduação | Não submete; só Lattes |
| Iniciação Científica | B3-B1 (revista local pode aceitar) |
| Mestrado | B1-A3 |
| Doutorado | A1-A3 |
| PPG nota 6-7 | A1-A2 obrigatório |
| Pesquisa de docente / PQ | A1-A2 |

## Cuidado com revistas predatórias

❌ Sinais de revista predatória:
- Cobra alto valor (US$ 500+) sem ser top tier
- Aceita em poucos dias (peer review nunca é tão rápido)
- Sem editor identificado
- Sem normas claras
- Não está em SciELO, Scopus, WoS, PubMed
- Domínio recente
- Está na **Beall's List** (https://beallslist.net) ou **Cabells Predatory Reports**

⚠️ Publicar em predatória **não conta no Lattes** e ainda **prejudica reputação**.

## Mudanças no Qualis (2025+)

CAPES está discutindo um novo modelo Qualis com base em:
- **Indicadores quantitativos uniformes** (CiteScore, SJR, h5-index)
- **Avaliação por área menos discricionária**
- **Diretrizes de DORA** (Declaration on Research Assessment)

Verifique sempre se o Qualis em vigor mudou, consultando o **Documento de Área** mais recente em:
- https://www.gov.br/capes/pt-br/acesso-a-informacao/acoes-e-programas/avaliacao

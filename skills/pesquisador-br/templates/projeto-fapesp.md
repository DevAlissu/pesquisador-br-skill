# Template: Projeto de Pesquisa FAPESP / FAPs Estaduais

> Estrutura para projetos de Fundações de Amparo à Pesquisa estaduais (FAPESP, FAPEAM, FAPERJ, FAPEMIG, FAPESC, FAPEMA, etc).

## Diferenças vs CNPq

| Aspecto | CNPq Universal | FAPESP/FAPs |
|---|---|---|
| Abrangência | Nacional | Estadual |
| Foco | Pesquisa básica + aplicada | Mais aplicada (pertinência regional) |
| Pareceres | Por área CAPES | Por câmara temática + parecerista ad hoc |
| Tempo de avaliação | 3-6 meses | 2-4 meses (FAPESP é mais rápida) |
| Valor médio | R$ 30-150 mil | Varia (FAPESP mais robusta) |
| Modalidades | Universal, PIBIC, PQ | Auxílio Regular, Inicial, Temático, JP, BPE |

## Estrutura típica (varia por FAP, mas estes campos são comuns)

```
1. IDENTIFICAÇÃO
   - Pesquisador responsável (Lattes, ORCID)
   - Instituição executora
   - Linha de fomento / modalidade
   - Duração

2. RESUMO + PALAVRAS-CHAVE

3. ENQUADRAMENTO TEMÁTICO
   - Linha de pesquisa da FAP
   - Edital ou programa específico

4. INTRODUÇÃO E JUSTIFICATIVA
   4.1 Tema e problema
   4.2 Lacuna na literatura
   4.3 Pertinência regional (importante!)

5. OBJETIVOS
   5.1 Geral
   5.2 Específicos

6. FUNDAMENTAÇÃO TEÓRICA

7. HIPÓTESES (se aplicável)

8. METODOLOGIA
   8.1 Tipo de pesquisa
   8.2 Sujeitos / corpus / dados
   8.3 Procedimentos de coleta
   8.4 Procedimentos de análise
   8.5 Aspectos éticos

9. CRONOGRAMA

10. ORÇAMENTO DETALHADO

11. RESULTADOS ESPERADOS / PRODUTOS

12. EQUIPE EXECUTORA (com CV resumido)

13. INFRAESTRUTURA DISPONÍVEL

14. REFERÊNCIAS

15. APÊNDICES (cartas de anuência, planos de trabalho)
```

## Especificidades FAPESP

### Modalidades principais

| Modalidade | Para quem |
|---|---|
| **Auxílio Regular à Pesquisa** | Pesquisador com vínculo institucional em SP |
| **Auxílio Inicial à Pesquisa** | Pesquisador recém-doutor (até 7 anos do título) |
| **Temático** | Pesquisador sênior, projeto de grande porte (5 anos) |
| **Jovem Pesquisador (JP)** | Doutor jovem, com perfil para liderar grupo |
| **BPE — Bolsa de Pesquisa no Exterior** | Estágio internacional |
| **Iniciação Científica** | Aluno de graduação |

### Critérios FAPESP
- **Mérito científico**
- **Adequação metodológica**
- **Currículo do pesquisador**
- **Infraestrutura disponível**
- **Adequação orçamentária**
- ⚠️ **Pertinência ao estado**: FAPESP exige pertinência ao território paulista

## Especificidades FAPEAM

### Modalidades

| Modalidade | Para quem |
|---|---|
| **PRO-ESTADO** | Pesquisador com vínculo em IES amazonense |
| **Universal Amazonas** | Edital amplo |
| **PAPAC** | Pesquisa Aplicada em Áreas Críticas |
| **POSGRAD** | Apoio à pós-graduação |
| **PCE — Programa Ciência na Escola** | Educação básica |

### Pertinência regional
FAPEAM valoriza pesquisa com **impacto na Amazônia**. Justifique como o projeto:
- Investiga problema regional
- Contribui pra desenvolvimento do estado
- Tem ligação com Bioeconomia, Saúde, Sustentabilidade

## Modelo: Resumo

```
A presente proposta investiga [tema] no contexto de [recorte
regional/setorial], frente à crescente demanda por [problema].
Justifica-se pela relevância acadêmica em [...] e pela pertinência
estratégica para o [estado/região], dado [evidência regional].
Tem como objetivo geral [objetivo]. Como objetivos específicos:
(a) [obj1]; (b) [obj2]; (c) [obj3]. A metodologia adota [tipo],
com [procedimentos]. A pesquisa será desenvolvida em [duração]
meses, com produção esperada de [N] artigos em revistas Qualis
A1-A2 e [N] participações em eventos. Espera-se contribuir com
[contribuição teórica] e [contribuição prática].

Palavras-chave: termo 1; termo 2; termo 3; termo 4; termo 5.
```

## Aspectos éticos

```
Todos os procedimentos serão submetidos ao Comitê de Ética em
Pesquisa da [Instituição] e cumprirão as diretrizes da Resolução
nº 466/2012 do Conselho Nacional de Saúde. Será obtido Termo de
Consentimento Livre e Esclarecido (TCLE) de todos os participantes.
A coleta e tratamento de dados respeitarão a Lei Geral de Proteção
de Dados Pessoais (Lei nº 13.709/2018), com anonimização e
armazenamento seguro.
```

## Checklist FAPESP/FAP

- [ ] Modalidade correta selecionada
- [ ] Edital específico identificado
- [ ] Pertinência regional claramente justificada
- [ ] Pesquisador responsável tem vínculo na IES do estado
- [ ] Currículo Lattes atualizado (últimos 5 anos)
- [ ] ORCID vinculado
- [ ] Cronograma realista
- [ ] Orçamento dentro do teto da modalidade
- [ ] Contrapartida institucional declarada
- [ ] Infraestrutura listada (laboratórios, equipamentos)
- [ ] Aspectos éticos contemplados
- [ ] Equipe com competências complementares
- [ ] Cartas de anuência (se interinstitucional)
- [ ] Referências NBR 6023 (mín 30)
